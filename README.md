# JavaScript Learning Progress Dashboard

## Project Description
This project is a JavaScript Learning Progress Dashboard developed using HTML, CSS, and JavaScript. It allows students to enter their learning details, validates the input, calculates a progress category, and displays JavaScript topics using an ES6 array method.

## Features
- Student Registration Form
- Input Validation
- Roll Number Last Digit Check (Even/Odd)
- Progress Category Calculation
- Display JavaScript Topics using ES6 `forEach()`
- Responsive and Simple User Interface

## Technologies Used
- HTML
- CSS
- JavaScript (ES6)

## Form Fields
- Name
- Roll Number
- Topics Completed
- Practice Hours
- Confidence Rating (1–10)

## Validation
- All fields are mandatory.
- Confidence Rating must be between 1 and 10.
- Displays whether the last digit of the Roll Number is Even or Odd.

## Progress Categories
- Excellent
- Good
- Needs Improvement

## JavaScript Topics Displayed
- Variables
- Functions
- DOM Manipulation

## How to Run
1. Download or clone the repository.
2. Open the project folder.
3. Double-click `index.html` or open it in any web browser.
4. Fill in the form and click **Submit**.
